# Générateurs des planches (optionnels)

Les planches `.html` sont autonomes : elles s'ouvrent sans ces scripts. Les scripts servent seulement à les régénérer après un `/delta`.

```bash
python3 build.py  ../planches/v1   # V1 : 3 directions
python3 build2.py ../planches/v2   # V2 : Jeu (Diorama)
python3 build3.py ../planches/v2   # V2 : Post + Carte de fin
```
